# Story of Toys — revision 99

A toy-sized bedroom rings course for Rocket League. Follow 100 rings through seven stages, land between matching colored stars at checkpoints, then explore the room after finishing. Touch the golden alien on the finish shelf to restart.

This is a playable work-in-progress build. Revision 99 joins the crib's end spindles to its arches, mounts the mobile on a curved support, and replaces the globe's segmented brass frame with a continuous ring.

## Install

Use an existing offline Rocket League setup with BakkesMod and Workshop Map Loader.

1. Extract this ZIP into the maps directory configured in Workshop Map Loader. Keep the complete `Story of Toys` folder, including its `.upk`, `info.json` and preview.
2. Refresh the loader's map list and select **Story of Toys**.
3. Load the map in your offline session. If an older version is already loaded, reload to use revision 99.

Keep an earlier download separately if you want to roll back. This ZIP does not include Rocket League, BakkesMod or the map loader.

## Status

The exact package passed 100 controlled physical ring crossings, all seven stages, invalid-approach checks, completion/exploration, restart and checkpoint reset. A short drive using ordinary W/S input stayed supported on the hat. Full-course flight using ordinary controls remains untested in this revision.

Fine striping on crib/trim surfaces and soft bedding artwork remain. Performance, other resolutions and exhaustive collision testing are pending. See `VALIDATION.md` for the scope of the checks and `CREDITS.md` for content notes.

The preview is an actual revision 99 game capture, not concept art.
