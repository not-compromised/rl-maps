## Generated images

- `wrecklight-coast/assets/ghost_sky.png` and its copy in `haunted-hold/assets/`
  were generated with an image-generation tool for this project. The prompt
  is kept in `assets/sky-prompt.txt`. It is an environment texture, not a
  render of map geometry.
- `story-of-toys/assets/andy-face/face-study-01.png` is an AI-generated face
  texture for the map's boy character, made with a film still as the identity
  reference (see the README beside it). It is part of the fan work described
  below.
